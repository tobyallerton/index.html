# Slideshow formats

Use this when the user's product has no strong trending slideshow to copy (mode C), or to label a format. A format that is currently winning on Social1 always beats this list. **Add to this file** whenever you find a new format that keeps winning: give its label, the slide-by-slide shape, and one example link.

| Label | Slide 1 hook shape | Usual structure (5–8 slides) | Suits |
|---|---|---|---|
| POV | "POV: you finally found …" | hook → problem → product reveal → in use → result shot → CTA | beauty, hair, home fixes |
| COMMENT-REPLY | Fake comment bubble: "I'm not spending £30 on that" → reply "it's literally £5 on sale" | comment hook → product → close-ups → price/value → CTA | cheap dupes, price-shock items |
| SELFIE | Mirror or front-camera selfie wearing/using it, short line | selfie hook → outfit/angle 2 → detail → in context → CTA | clothing, accessories, winter wear |
| LIST | "5 things I'd rebuy …" / "things that just make sense" | hook → one item per slide (our product is one, usually 2nd or 3rd, plus generic non-branded items) → CTA | home, gadgets, gifting |
| BEFORE-AFTER | "Week 1 vs week 6" style | hook → before → product → routine → after → CTA. Only with results the listing itself shows; never invent results | cleaning, organising (not health or body) |
| GIFT | "Gift ideas for the girl who has everything" | hook → wrapped/gift setting → product → detail → reaction → CTA | perfume, jewellery, gadgets |
| DUPE | "The £x dupe for the £y one" | hook → product → side-by-side feel (no other brand logos) → close-up → CTA | perfume, beauty, fashion |
| ROUTINE | "My 5-minute morning routine" | hook → step slides with the product as one step → final look → CTA | skincare, hair, wellness tools |
| UNBOXING | "What I got for £10 on TikTok Shop" | hook → parcel → reveal → close-ups → in use → CTA | cheap hauls, multi-packs |

Notes:
- For COMMENT-REPLY, build the comment bubble as part of the slide text with `style: box`, or ask ChatGPT for a phone screenshot look with no readable usernames. Never copy a real user's name or photo.
- DUPE and LIST must not show other brands' logos or packaging.
